# Terminal

Write a terminal in C. 

## What is a terminal?

A terminal, as intended here, is a *terminal emulatoar*, which is a piece of software, a graphical one, which allows to run command line applications. Basically any piece of software, which doesn't have a graphical interface on its own and which requires any form of interaction with the user (like the user being able to start that program or to read the output of that porgram) needs to be run in a terminal. 

The most famous program, which runs in the terminal is the shell.
